# nmap-basics
Nmap stands for Network Mapper. It is a free tool used to scan networks. It helps find connected devices, open ports, running services, and sometimes the operating system. Nmap is mainly used by network administrators and cybersecurity professionals for network checking, troubleshooting, and security testing. It should be used only with permission.
